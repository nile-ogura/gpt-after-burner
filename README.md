# AFTERBURNER / HORIZON

Three.jsで制作した、戦闘機の後方視点による3Dアーケードシューティングです。参考動画のステージ構造と基本ルールを確認し、オリジナルの機体と景観で実装しています。

## 起動

Node.js 22.12以上とpnpmを使用します。

```sh
pnpm install
pnpm dev
```

`http://localhost:5173` を開いて「出撃する」を選択します。このワークスペースでは開発サーバーを起動済みです。

```sh
pnpm test
pnpm build
pnpm preview
```

## 操作

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| 操縦 | WASD / 矢印 | 左スティック |
| 機銃 | Space | A / 下ボタン |
| ロック後のミサイル | J | B / 右ボタン |
| HIスロットル | Shift | RT |
| LOWスロットル | K | LT |
| 360度ロール（左 / 右） | Q / E | LB / RB |
| 目標切り替え | Tab | 自動取得 |
| 一時停止 | Esc | 画面のPAUSE |
| フレア（設定で追加） | F | X / 左ボタン |

タッチ環境では画面上の操縦桿・射撃・加減速・左右ロールボタンを利用できます。ロールは1回転後に復帰し、押し続けても連続しません。無敵効果はありません。操作割り当てと回転時間は現代向けの調整です。

## 参考資料に沿った進行と実装上の調整

- 全23ステージ。3・9・11・16・19・21面に空中補給、5・13面に滑走路での補給、8・17面に低空区間、23面に空母帰還。
- 機銃は無制限。ミサイルの初期50発・補給時50発・最大100発は、この実装での調整です。これらの数値を参考動画から直接確認したとは扱っていません。原作の隠し100発補給コマンドは実装していません。
- 最大4目標を捕捉し、弾数とロック状態に応じて順次ミサイルを発射。
- ステージHITは撃墜数で、ステージ移行時にリセット。動画の集計表示で確認したステージ終了ボーナスはHIT×20,000。累計HITの機銃1・ミサイル2は、補足の攻略記事に基づいています。
- 3機の残機。全機を失うとGAME OVER。ハイスコアをブラウザに保存。

出現座標、個別撃墜得点、機体ごとの体力、ミサイル容量、慣性・誘導・回避挙動は現代向けの調整です。各ルールの観察・補足資料・調整の区分は [参照記録](docs/REFERENCES.md) に記載しています。原作ROMのエミュレーションではありません。フレアは追加機能で、初期設定では無効です。XPによるレベルアップや架空のボス進行はありません。

## 実装と検証

このPCでは低FPSを許容する、という指定を適用しています。初期設定は高品質です。保存済みの手動設定は維持します。描画速度の測定値は記録しますが、低FPSを理由に採用を止めず、見た目・操作や戦闘の正しさ・参考動画に沿った進行を優先します。新規ブラウザーで12描画フレーム後も高品質・影・ブルームが維持されることを確認しています。

独自の曲面機体、PBR素材、パネル・リベット・汚れ、可動舵面と脚、金属ノズルの内部構造と排気、海面シェーダー、山岳沿岸、3種類の独自生成雲素材、雲を含む静的反射、機体の自己影、後方追従カメラと360度背景ロール、HUD・レーダー、誘導弾・機銃・爆発、Web Audioを実装しています。描画品質の自動調整・上下反転・音声・操作説明・一時停止・再出撃を利用できます。

22項目のシミュレーションテストで、フレームレートに依存しない飛行、武器・衝突・回避、HIT集計、残機、補給、着陸、通常時間での全23面完走、左右ロール・停止・復帰・戦闘との整合を検証しています。ブラウザでもキー入力による射撃、タッチイベントによる操縦・射撃・ボタンを離した際の停止・ロールの復帰、停止と再開、タイトル帰還、補給・空母と滑走路への接地・最終帰還後の再出撃を確認しています。静止画の見た目と、実行試験の結果は分けて記録しています。

実装者と別の批評担当がレビューし、公式ACE COMBAT 8画像とのA/B比較を行っています。**商用AAAと同等とは判定されていません。** round9の出典を伏せた比較では、独立批評担当と機体・景観の担当が先にBを選び、その後Bが公式画像と確認しました。既知の画風があるため完全な盲検ではありません。前のround7では履歴を引き継がない批評役も公式側を選んでいます。縦画面は390px/320pxの26条件で独立検査を通過し、自機と下部計器の重なり、左右端の目標情報、通信表示を修正しました。静止した検証状態での合格で、全入力・全状況の保証ではありません。写実的な雲・地形・機体の密度、音声・コンテンツ量、実GPU上での性能評価には差と未検証事項があります。森林修正前のステージ1で行ったSwiftShaderによる1440×900の停止中フレーム測定は高品質1.20fps、軽量診断設定3.21fpsで、この環境の滑らかさの基準は未達です。実GPUでの60fpsは未検証です。
